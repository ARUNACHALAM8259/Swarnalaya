# Logo Placement Instructions

## How to Add Your Swarnalaya Logo

1. **Save Your Logo**
   - You have provided a beautiful Swarnalaya logo with "Gold | Silver | Diamond | Platinum" text
   - Save this logo as `logo.png` in the main project folder

2. **File Location**

   ```
   swarnalaya/
   ├── logo.png          ← Place your logo here
   ├── index.html
   ├── styles.css
   └── script.js
   ```

3. **Logo Specifications**
   - Format: PNG, JPG, or SVG (recommended: PNG or SVG for quality)
   - Recommended Width: 200px
   - Height: Auto (will adjust proportionally)
   - Transparency: PNG recommended for transparent background

4. **If Logo Doesn't Show**
   - Verify file is named exactly `logo.png`
   - Check file is in the same folder as `index.html`
   - Refresh your browser (Ctrl+F5 or Cmd+Shift+R)

## Quick Start Without Logo

If you want to test the website before adding your logo:

1. Open `index.html` in your browser
2. The search bar and navigation menu will work fine
3. You'll see a placeholder for the logo area (shown as image not found)
4. Once you add `logo.png`, refresh the page and it will appear
