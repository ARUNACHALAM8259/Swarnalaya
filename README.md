# Swarnalaya - Premium Jewelry Website

A beautiful, responsive jewelry website for Swarnalaya featuring Gold, Silver, Diamond, and Platinum collections.

## Project Structure

```
swarnalaya/
├── index.html          # Main HTML file
├── styles.css          # Stylesheet
├── script.js           # JavaScript functionality
├── logo.png            # Swarnalaya logo (add your logo here)
└── README.md           # This file
```

## Getting Started

1. **Add Your Logo**
   - Replace `logo.png` with your Swarnalaya logo
   - Logo path: `swarnalaya/logo.png`
   - Recommended size: 200px width (auto height)

2. **Open in Browser**
   - Simply open `index.html` in your web browser
   - No build tools or dependencies required

3. **Customize**
   - Edit colors in `styles.css` (`:root` CSS variables)
   - Modify menu items in `index.html`
   - Add functionality in `script.js`
